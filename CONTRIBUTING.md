# Contributing to FairShare

Thanks for considering a contribution.

## Before opening an issue

- Search existing issues to avoid duplicates.
- Include the browser and operating system when reporting a UI problem.
- Include sample steps and expected versus actual results.
- Never attach real financial records, personal information or credentials.

## Development

1. Fork the repository and create a focused branch.
2. Run the app with \`python3 -m http.server 4173\`.
3. Run \`npm test\` before submitting changes.
4. Add or update tests when changing monetary calculations.
5. Keep dependencies small and document any new runtime requirements.

## Pull requests

Keep pull requests focused. Describe the user-visible change, the reason for it, and how you tested it. UI changes should remain usable on narrow mobile screens and with keyboard navigation.
